# OSFH Chat Wrapper 仕様書

更新日: 2026-09-03
対象: `mobile-wrapper/`
状態: Android試作・切り分け中

## 1. 目的

Android上にChatGPT専用入口を用意し、ChatGPT Webを利用しながら、将来的にOS_FOR_HUMAN向けの会話ログ保存・スレッド識別・時刻表示・ファイル添付等を追加する。

このアプリは現段階ではChatGPTの独自クライアントAPI実装ではなく、Android WebViewで `https://chatgpt.com/` を開くラッパーである。

## 2. 現在の構成

- package/applicationId: `com.osfh.chatwrapper`
- minSdk: 26
- targetSdk: 35
- compileSdk: 35
- Java Activity + Android WebView
- Cookieを許可
- JavaScript / DOM Storage / Databaseを有効化
- GitHub Actionsでdebug APKを生成
- 固定の試作署名を使用し、同一署名・versionCode増加で上書き更新する

## 3. ここまでに確認できたこと

### 3.1 初期版

ChatGPT WebをWebViewで表示し、JavaScriptのMutationObserverで `[data-message-author-role]` を監視した。

ユーザー/assistant本文を `chat_log.jsonl` に保存する試作を実装した。

追加試作として以下も実装した。

- スレッド名相当の固定ヘッダー
- 各メッセージへの時刻表示
- WebViewフォーカス強制

注意: この時刻は本来の送信時刻ではなく、ラッパーがそのメッセージを観測した時刻である。真の送信時刻として扱わない。

### 3.2 操作不能の切り分け

一時的に「左上のメニュー以外が押せない」ように見える事象が発生したため、以下を全て外したベースライン版 v0.2.1 を作成した。

- DOM injection
- MutationObserverによるログ取得
- JavascriptInterface
- User-Agent書き換え
- フォーカス強制

v0.2.1はChatGPTをほぼ素のWebViewで開く切り分け版。

その後、操作不能と見えた一部事象はChatGPT公式アプリ側で発生していたことも確認されたため、専用ラッパー固有の障害と断定しない。

### 3.3 画像・ファイル添付

ベースライン版では `WebChromeClient.onShowFileChooser` を実装していないため、Web側がファイル選択を要求してもAndroidのファイル選択へ橋渡しできない。

完成版では画像・複数画像・PDF/一般ファイルを扱えるファイル選択経路を実装する。

### 3.4 回答非表示

v0.2.1で、ユーザーメッセージは送信・表示される一方、assistant回答がWebViewに表示されない事象を確認。

切り分けとして v0.2.2 ではDOM監視等を戻さず、User-Agentのみブラウザ寄りに戻した。

v0.2.2でも回答が表示されないことを確認したため、「UA書き換えを外したことだけが原因」という仮説は棄却する。

現時点では、WebView内でのChatGPT回答ストリーム/JS描画/通信のどこで停止しているか未確定。推測で原因を固定しない。

## 4. UI要件

完成版では少なくとも以下を満たす。

- ChatGPTの通常操作を阻害しない
- 入力欄・送信・メニュー・スレッド選択が常時操作可能
- ソフトキーボード表示時にも入力UIが隠れない
- スレッド名を分かる形で表示
- メッセージ時刻を表示する場合、観測時刻と送信時刻を混同しない
- 画像/ファイル添付をAndroid選択UIへ接続
- 送信後、回答がまだ画面に現れていない間は「回答を待っています」等の状態表示を出す
- 一定時間回答を確認できない場合、無限待機にせず「回答を表示できていません」等へ遷移する
- 待機表示そのものがChatGPT DOM操作を邪魔しない

## 5. ログ要件

最終的に保存対象候補:

- 観測時刻
- role (`user` / `assistant`)
- 本文
- URL / conversation識別情報
- スレッドタイトル
- アプリ版

ログ機能を再導入する際は、表示・入力・回答ストリームを壊さないことをE2E確認してから次機能を足す。

## 6. 再導入順序

ベースラインから以下の順に1機能ずつ戻す。

1. ChatGPTの送信→回答表示を安定化
2. 回答待機/タイムアウト表示
3. 画像・ファイル添付
4. ログ保存のみ
5. スレッド識別/タイトル表示
6. 時刻表示
7. 必要な追加UI

各段階で前段のE2Eテストを再実施する。複数機能を同時に戻して原因不明にしない。

## 7. 署名・更新仕様

初期のGitHub Actions debug buildではランナーごとにdebug署名が変わり得る構成だったため、旧APKから別ビルドへの上書きインストールで問題が発生した。

以後は試作用固定署名を使う構成へ変更済み。`versionCode` はリリースごとに必ず増加させる。

注意: 現在の固定署名は試作用。公開配布・本番運用では秘密鍵を公開リポジトリに置かず、安全な署名管理へ移行する。
